    Type Alias Source

    A source, such as a book or a website, that a document's citations and bibliographies refer to. Its tag is how a Citation names it.

    Every field is text as Word keeps it, and each style of citation writes it as it's given: a month such as "March", pages such as "50-62", and an edition such as "2nd". Which fields a style writes depends on the type of the source, and each field's description says which types of source Word asks for it with.
