    Optional Readonlynotes

    notes?: "footnotes" | "endnotes"

    What the HTML's notes are in Word, such as the footnotes of Markdown, Pandoc and Google Docs: "footnotes", at the foot of the page each is referred to on, by default, or "endnotes", at the end of the document, as a web page has them.     Optional ReadonlystyleMap

    styleMap?: Readonly<Record<string, string>>

    The Word styles to give the elements that CSS selectors match, by the styles' ids, such as { "p.lead": "Lead", "blockquote": "Quote", "code": "InlineCode", "table": "GridTable4" }. A block is given a paragraph style, an inline element a character style, and a table a table style. When selectors that match an element give it different styles, the most specific selector's is used, as in CSS. The styles must be in the document, such as in its styles option or the template it patches.

    Optional ReadonlytrackChanges

    trackChanges?: { author: string; date?: string }

    Turns <ins> and <del>, such as an HTML diff's, into Word's tracked changes, by this author, and at the time of their datetime attribute, or this time, or now: an ISO 8601 date and time such as 2026-10-13T09:30:00Z. Without it, they are underlined and struck through, as a browser shows them.
