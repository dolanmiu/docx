    • Optional Readonlyfill?: ShapeFill

    • Optional Readonlyfloating?: IFloating

      Floats the canvas on the page instead of placing it inline with text

    • Optional Readonlylayout?: ShapeLayout

      Places the shapes, pictures and groups that have no offset: in levels along their connectors like a flowchart, as a tree like an org chart, or in a grid

    • Optional Readonlyline?: ShapeLine

      The canvas's outline. Default is none

    • Optional Readonlytransformation?: { height: number; width: number }

      Size of the canvas in pixels. Defaults to reaching from the top-left corner to the right and bottom of the shapes, including their lines and effects, so an offset leaves space above and to the left of a shape. The shapes are not scaled.
