    Type Alias VmlShapeStyle

    Styling options for VML shapes.

    This type defines all available CSS-like styling properties for positioning, sizing, and configuring VML shapes in WordprocessingML documents. These properties control the shape's appearance, layout, and interaction with surrounding text.

    Properties are emitted in the order they are declared on the object.
