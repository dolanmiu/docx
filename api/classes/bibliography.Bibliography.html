    Class Bibliography

    A bibliography: the list of the document's sources, in the style of its citations, as Word's References > Bibliography inserts it. It lists every source of the document's bibliography, cited or not, and Word writes it again when it updates the document's fields, or when the style is changed.

    The document needs its sources: give it bibliography: createBibliography({ sources }).

    Public Api

    Example

    // As Word's built-in "References" bibliography: a heading, then the list
    new Bibliography({ title: "References" });
